ComfyUI Model Archive

Privacy policy

Effective November 16, 2026. Operator: Sugar Mint. Contact: sugarmintart@gmail.com.

Information accessed and why

This personal desktop application uses Google's drive.file permission to create, find, upload, and download model archives that it created or that the user explicitly made available to it. It uses file identifiers, names, sizes, checksums, and transfer status to locate archives and verify restoration. It does not request access to unrelated Drive files, Gmail, contacts, or calendars.

Storage and protection

Encrypted model archives are stored in the user's Google Drive account. Decryption keys stay on the user's computer. OAuth credentials and refresh tokens are stored locally with restricted filesystem access, so rclone can restore files without requiring a sign-in for every run. Local configuration, integrity checksums, and diagnostic records support restoration and troubleshooting. Restored models remain on the computer until the user removes or archives them.

Use and sharing

Google API data is used only to provide and troubleshoot model archiving and restoration. It is not sold, used for advertising, or used to train AI models. Transfers go between the user's computer and Google Drive. This application has no separate hosted service receiving archive contents or credentials. An optional agent-help action copies a diagnostic request for the user to review and share; it does not automatically send data to an agent. Any information the user subsequently shares is handled under the selected agent service's policies.

ComfyUI Model Archive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation, and deletion

Archives remain in the user's Drive until the user deletes them. Local models, credentials, keys, configuration, and diagnostic records remain until the user removes them. Access can be revoked through Google Account connections. Revoking access stops future authorized transfers but does not itself delete existing cloud or local files. The user controls deletion in Google Drive and on their computer.

This information website

This static site does not run analytics, use tracking cookies, or collect form submissions. GitHub Pages hosts it and may process ordinary access information under the GitHub Privacy Statement. Emailing the contact address voluntarily shares the message and sender address for responding to the request.

Changes and contact
