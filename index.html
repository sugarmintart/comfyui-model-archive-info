ComfyUI Model Archive

Keep seldom-used models in your own Google Drive. Restore them locally when a ComfyUI workflow needs them.

How it works

This personal desktop integration uses rclone to store encrypted model archives in Google Drive. When a registered model is needed, it downloads and decrypts the archive on the owner's computer, verifies the model, and shows restoration progress before generation starts.

Limited Google Drive access

The integration requests only the drive.file permission: access to files it creates or files explicitly shared with the application. It does not request access to the whole Drive.

About this site

This is an information site for a personal application operated by Sugar Mint. It is not a hosted model service and does not accept uploads or Google sign-ins. Model files and login credentials are never published here.
